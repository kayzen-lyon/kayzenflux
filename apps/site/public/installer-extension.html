Installer l'extension

Version 1.0.0 — extension, APK Android et installeur Windows.

L'extension n'est pas encore publiée sur les boutiques des navigateurs. En attendant, elle s'installe à la main à partir du fichier .zip. Elle bloque les publicités pendant la lecture, saute les segments sponsorisés et ouvre KAYZEN Flux avec le lien de la page. Elle ne télécharge rien elle-même.

Chrome, Edge ou Brave

Télécharger l'extension pour Chrome, Edge et Brave (.zip)

  1. Décompressez le fichier kayzen-flux-extension-chromium-1.0.0.zip dans un dossier que vous garderez (par exemple Documents). Ne supprimez pas ce dossier après l'installation : le navigateur en a besoin.
  2. Ouvrez la page des extensions : tapez chrome://extensions dans la barre d'adresse (edge://extensions dans Edge, brave://extensions dans Brave).
  3. Activez le Mode développeur (interrupteur en haut à droite dans Chrome, dans la colonne de gauche dans Edge).
  4. Cliquez sur Charger l'extension non empaquetée et choisissez le dossier décompressé, celui qui contient le fichier manifest.json.
  5. Épinglez l'extension depuis l'icône en forme de pièce de puzzle pour l'avoir sous la main.

Au démarrage, le navigateur peut signaler qu'une extension en mode développeur est active : c'est normal pour une installation manuelle.

Firefox

Télécharger l'extension pour Firefox (.zip)

  1. Tapez about:debugging#/runtime/this-firefox dans la barre d'adresse.
  2. Cliquez sur Charger un module complémentaire temporaire….
  3. Sélectionnez directement le fichier kayzen-flux-extension-firefox-1.0.0.zip (inutile de le décompresser).

Limite de Firefox : un module chargé de cette façon est retiré à la fermeture du navigateur. Il faut refaire ces étapes à chaque redémarrage, jusqu'à la publication de l'extension sur la boutique de modules Firefox.

Application Android (APK)

Télécharger l'APK Android

KAYZEN Flux pour Android n'est pas distribué sur le Play Store. Pour l'installer :

  1. Téléchargez le fichier kayzen-flux-1.0.0-android.apk depuis votre téléphone, puis ouvrez-le.
  2. Android indique que votre navigateur n'est pas autorisé à installer des applications : touchez Paramètres, activez Autoriser cette source, puis revenez en arrière.
  3. Touchez Installer. Vous pouvez ensuite retirer l'autorisation donnée au navigateur.

Les intitulés exacts varient selon la marque du téléphone et la version d'Android.

Avertissement Windows SmartScreen

L'installeur Windows n'est pas encore signé numériquement. Au lancement, Windows peut afficher « Windows a protégé votre ordinateur ».

  1. Cliquez sur Informations complémentaires.
  2. Vérifiez que l'éditeur et le nom du fichier correspondent à kayzen-flux-1.0.0-win-x64.exe, téléchargé depuis telechargements.kayzen-lyon.com.
  3. Cliquez sur Exécuter quand même.
